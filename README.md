# Мозаика — мастерская блоков

Мобильное приложение для схем термомозаики, оформленное в духе блочных игр.
Работает без сервера, аккаунтов и платных API. Все ресурсы включены в приложение.

## Возможности

- Палитры и запасы раздельно для деталей 5 мм и 2,6 мм.
- Подбор оттенка, точный/примерный подсчёт или «Много / Средне / Мало / Нету».
- Квадрат 29×29, круг и шестиугольник по 631 месту; квадрат 104×104 для мини-деталей.
- Преобразование фото только в имеющиеся цвета, ограничение числа цветов.
- Удаление светлого фона у краёв, поворот, размещение.
- Подсчёт расхода, подбор доступного цвета для замены, кисть, ластик, отмена.
- Сохранение готовых схем и исходных картинок в IndexedDB на устройстве.
- PNG с изображением или схемой и расходом; полная резервная копия JSON.
- Установка на главный экран Android и офлайн-режим после первого открытия.
- Реальный бесплатный поиск открывается в Яндексе/Google. Картинку нужно скачать и выбрать в приложении.

## Запуск и размещение

Папка dist/ содержит готовый сайт. Нужен обычный HTTPS-хостинг без серверных функций.
Можно размещать в подпапке. Не открывайте index.html через file://: для PWA нужен HTTP/HTTPS.
Для локальной проверки: node tools/serve.cjs, затем открыть напечатанный адрес.

Для GitHub Pages: загрузить файлы dist/ в корень публичного репозитория,
затем Settings → Pages → Deploy from a branch → main → / (root).

## Хранение данных

Данные привязаны к адресу сайта, устройству и браузеру. Между телефонами автоматически не синхронизируются.
Установка PWA из того же браузера использует то же хранилище. Очистка данных сайта удаляет запасы и схемы.
Кнопка «Копия и восстановление» экспортирует и импортирует весь сундук вместе с картинками.
Восстановление выполняется одной транзакцией после проверки всех данных.
Защита от перезаписи из второй вкладки: запись проверяет ревизию хранилища.
Статус «Сохранено» появляется только после успешного завершения транзакции.

Сайт не отправляет фотографии, запасы или схемы на сервер. Внешние обращения приложения —
только выбранный ребёнком поиск и загрузка самой страницы/обновлений.

## Поддержка

Подходит для современных Android-браузеров с IndexedDB, Canvas и Service Worker.
Для цветов использовано расстояние в Oklab; приблизительные запасы не превращаются в выдуманные числа.
Шаг и фазы круговых рядов стоит сверить с физической основой перед большой сборкой.
При обновлении статических файлов увеличивайте версию кеша в sw.js.
Иконки и пиксельные рисунки созданы для проекта, ресурсы из игры не загружаются.
