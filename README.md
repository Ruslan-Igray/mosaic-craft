# Мозаика — мастерская блоков

Мобильное приложение для схем термомозаики, оформленное в духе блочных игр.
Работает без сервера, аккаунтов и платных API. Все ресурсы включены в приложение.

Открыть: https://ruslan-igray.github.io/mosaic-craft/

## Версия 1.3.0

- Редактор цвета помещается в одном окне: 12 закрашенных базовых плашек в сетке 3×4,
  живая деталь, ползунок, пипетка, оттенок и запас. Отдельного второго шага больше нет.
- Базовую сетку можно менять кнопкой с карандашом. Выберите плашку, настройте оттенок,
  нажмите «Сохранить плашку», затем «Готово». Эти настройки сохраняются вместе с сундуком.
  Базовые плашки служат образцами: в запасы попадают только цвета, которые ребёнок добавил сам.
- Запас задаётся словами «Много / Средне / Мало» или числом с выбором «Точно / Примерно».
  При появлении клавиатуры поле количества и сохранение остаются видимыми.
- «Удалить» убирает цвет из запасов после подтверждения. Существующие схемы сохраняют свои цвета.
  Новым цветам присваиваются новые номера, включая случаи удаления и повторного добавления.
- Пипетка выбирает точный цвет пикселя из текущей или отдельно загруженной картинки.
  Картинка обрабатывается на устройстве и не отправляется на сервер.
- «Свободный крафт» открывает чистую основу выбранного размера и формы.
  Кисть рисует цветами из запасов, ластик убирает детали, «Двигать» и масштаб помогают с мелкой сеткой.
  Дополнительные цвета доступны стрелками. Рисование также открывается из готовой схемы.
- «Назад / Вперёд» отменяют и возвращают целый штрих. «Очистить всё» очищает рисунок одним действием,
  которое тоже можно отменить. Рисунки автоматически сохраняются в «Мои работы» и скачиваются в PNG.
- Резервная копия включает базовую сетку, запасы, рисунки и историю правок.

Проверены обновление 1.2.0 → 1.3.0 с сохранением запасов, фотографий и схем, восстановление новой
копии, проверка повреждённых правок до записи, пипетка, удаление, кисть, ластик, очистка и отмена,
PNG и офлайн-работа. Редактор, модальные окна и холст проверены без прокрутки на семи размерах экрана
от 320×480 до 1366×768, а ввод количества — при уменьшении экрана клавиатурой до 320×300.

- Уведомления, секреты и обновление открываются поверх экрана с кнопкой закрытия.

## Версия 1.1.0

- Номер версии и кнопка «Проверить обновления» видны внизу каждого экрана.
- Успешная онлайн-проверка подтверждает последнюю версию; отсутствие интернета или ошибка сервера показываются отдельно.
- Новая версия устанавливается по кнопке после завершения сохранения. Несохранённый цвет защищён от случайной перезагрузки.

- Наличие пяти цветов не означает обязательное использование всех пяти: сопоставляются ближайшие оттенки картинки.
- Старые схемы сохраняют исходные детали и правки. Новый подбор применяется при создании новой схемы.

Проверены генерация контрольного изображения во все пять совпадающих цветов, ограничение до двух,
исключение отсутствующего цвета, обновление со старой 1.0.0, сохранность фотографий/схем/запасов,
поиск следующей версии без закрытия приложения и офлайн-работа после обновления.

## Возможности

- Палитры и запасы раздельно для деталей 5 мм и 2,6 мм.
- Подбор оттенка, пипетка из картинки, точный/примерный подсчёт или «Много / Средне / Мало»; удаление цвета.
- Квадрат 29×29, круг и шестиугольник по 631 месту; квадрат 104×104 для мини-деталей.
- Преобразование фото только в имеющиеся цвета, ограничение числа цветов.
- Удаление светлого фона у краёв, поворот, размещение.
- Подсчёт расхода, подбор доступного цвета для замены, свободное рисование, кисть, ластик, отмена и возврат.
- Сохранение готовых схем и исходных картинок в IndexedDB на устройстве.
- PNG с изображением или схемой и расходом; полная резервная копия JSON.
- Установка на главный экран Android и офлайн-режим после первого открытия.
- Реальный бесплатный поиск открывается в Яндексе/Google. Картинку нужно скачать и выбрать в приложении.

## Запуск и размещение

Папка dist/ содержит готовый сайт. Нужен обычный HTTPS-хостинг без серверных функций.
Можно размещать в подпапке. Не открывайте index.html через file://: для PWA нужен HTTP/HTTPS.
Для локальной проверки: node tools/serve.cjs, затем открыть напечатанный адрес.

В этом репозитории уже настроено размещение через GitHub Actions: после изменения main
публикуется dist/, а проверка сравнивает опубликованные файлы с файлами выпуска.
Иконки восстанавливаются из tools/icon-assets.json скриптом tools/materialize-icons.py.

Подготовка следующего выпуска: node tools/finalize.cjs 1.3.0 (подставить новый номер).
Он синхронно создаёт version.json, version.js, ссылки на ресурсы и версию офлайн-кеша.
Для ещё не опубликованного кандидата допустим флаг --draft.
Все изменённые файлы выпуска следует загружать одним коммитом.

## Хранение данных

Данные привязаны к адресу сайта, устройству и браузеру. Между телефонами автоматически не синхронизируются.
Установка PWA из того же браузера использует то же хранилище. Очистка данных сайта удаляет запасы и схемы.
Кнопка «Копия и восстановление» экспортирует и импортирует весь сундук вместе с картинками.
Восстановление выполняется одной транзакцией после проверки всех данных.
Защита от перезаписи из второй вкладки: запись проверяет ревизию хранилища.
Статус «Сохранено» появляется только после успешного завершения транзакции.

Сайт не отправляет фотографии, запасы или схемы на сервер. Внешние обращения приложения —
только выбранный ребёнком поиск и загрузка самой страницы/обновлений.

## Поддержка

Подходит для современных Android-браузеров с IndexedDB, Canvas и Service Worker.
Для цветов использовано расстояние в Oklab; приблизительные запасы не превращаются в выдуманные числа.
Шаг и фазы круговых рядов стоит сверить с физической основой перед большой сборкой.
При обновлении статических файлов увеличивайте версию кеша в sw.js.
Иконки и пиксельные рисунки созданы для проекта, ресурсы из игры не загружаются.
